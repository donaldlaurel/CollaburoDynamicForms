Create Event field inventory

Everything currently on the createevent wizard: text fields with user vs admin required, selects with option values, and checkbox groups with names and options.

Required for users, not for admin Logged-in admin (or Hazel) uses relaxed validation. Only Client First Name stays required. Every other visible field can be saved empty. Customers auto-require visible fields unless marked optional, including Email and Phone. Lounge Area is an admin-only venue toggle.

How to read this list

Text / number / textarea: User Required means the customer cannot continue with it empty when the field is visible. Admin Required is almost always Optional, except Client First Name.

Select: Name is the form name. Options show label (saved value). Ranges like 1 to 20 are quantity dropdowns.

Checkbox group: Name lists member field names. Options show each checkbox label and the value saved when checked.

Source: createevent.php wizard includes as of 21 Sep 2026. Layout, rentals, and services repeat per venue (Main Hall, Large Room, Small Room, Back Patio).
